Kalin Gmail MCP

Kalin Gmail MCP is a private single-user application running on the owner’s own Linux computer. It connects to the owner’s Gmail account through the official Gmail API only after the owner authorizes access with Google OAuth.

At the owner’s request, the app can search and read email, view threads, manage labels, create drafts, send or reply to messages, move messages to Trash, and download attachments locally. The owner uses it through a private AI assistant integration. It is not offered to the public or used as a commercial service.

This informational website has no login form and does not collect email messages or passwords.

The app’s use of information received from Gmail APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
